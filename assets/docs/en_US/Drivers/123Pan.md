# 123Pan

This guide applies to `123Pan`.

## Good For

- Browsing 123Pan folders.
- Logging in with username/password or importing `access_token`.
- Downloading, uploading, mkdir, remove, rename, and move.

## Mount

1. Open <kbd>Dock</kbd> -> <kbd>Mounts</kbd> -> <kbd>Add</kbd>.
2. Select `123Pan`.
3. Set Mount Path to `/123`.
4. Fill `username` and `password`, or provide an existing `access_token`.
5. Keep `root_folder_id` as `0`.
6. Save, then browse `/123`.

| Recommended field | Value |
| --- | --- |
| Driver | `123Pan` |
| Mount path | `/123` |
| `root_folder_id` | `0` |
| `UploadThread` | `3` |

## Fields

| Field | Description |
| --- | --- |
| `username` / `password` | Required login credentials |
| `access_token` | Existing access token |
| `root_folder_id` | Root folder ID, default `0` |
| `UploadThread` | Upload concurrency |
| `platform` | API platform header, default `web` |

## Notes

- Runtime supports list, get, read, link, mkdir, remove, rename, move, and upload.
- Downloads prefer proxy paths.
- Upload uses presigned chunks or S3 upload according to upstream response.

## Troubleshooting

| Symptom | Try |
| --- | --- |
| Login fails | Check credentials, or clear expired `access_token` and retry |
| Upload fails | Check target permission and network stability |
| Link expired | Refresh the folder or reopen the file |
