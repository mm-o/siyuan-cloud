## 0.3.7

### 修复

- Dock 用户管理中不再为内置 `admin` 和 `guest` 用户显示删除按钮。
- 分享列表外层直接显示“复制链接”，并把“编辑分享”移入“更多”菜单。
- 统一资源 URL 编码规范，修复 Local 本地图片预览和复制中文文件名路径的编码问题，并让网盘/代理复制链接中的中文路径保持可读。
- 打开思盘说明文档时，通过思源 message 提示不要直接编辑打包文档内容。
- 补齐 Dock 中可选运行时驱动的中英文挂载说明，并在 README 驱动列表中链接到对应文档。
- 新增思源工作空间驱动说明，写明工作空间根目录挂载、原生公开资源链接和稳定复制链接行为。
- 修复 `assets/docs` 打包复制规则，避免驱动说明在发布包中重复生成根目录、语言目录和分类目录三份副本。
- 修复思源工作空间中媒体、图片和 PDF 预览失败的问题：工作空间 `data/<name>/...` 文件会直接走思源原生公开资源路径，不再绕到插件私有 `/p` 代理链接。
- 修复 WebDAV 图片预览和目录点击的边界问题：列表/获取对象改按 OpenList 的 PROPFIND 流程处理，避免图片查看器跳到第一张、错误处理函数未定义，以及目录自身响应被当作子项的问题。

### 优化

- 将挂载页右上角“添加”动作替换为“挂载说明”入口，打开打包的驱动说明索引；底部“添加”仍作为创建挂载入口。
- 在 OpenList 兼容挂载说明中补充 OpenList token 获取工具链接。
- 按 OpenList 上游百度网盘文档重写百度网盘驱动说明，补充 refresh token 获取、`download_api` 选择、上传字段和逐项测试清单。
- 停止把 `SiYuanKernel` 作为可添加驱动暴露；虚拟 FS 保持为思盘内置根能力，`SiYuanWorkspace` 作为唯一可手动添加的思源内置挂载，旧 `/` 内核挂载会从配置中清理。
- 统一思源工作空间公开资源的复制链接格式，复制结果使用 `/assets/...` 等稳定相对路径，不再带会变化的 localhost 地址和端口。
- WebDAV 运行时按 OpenList/gowebdav 的命名和主流程重整：`ReadDir` 使用 `PROPFIND Depth:1`，`Stat` 使用 `PROPFIND Depth:0`，对象名优先取 href basename，驱动层不再注入 UI 专用 `raw_url`。
- 将 FileTab 与 Dock 的文件 UI 行为收敛到共享 `file_ui` 和 `file_actions`：图片查看器、下载、复制链接、分享、删除和右键菜单统一维护一套。

### 新增

- 新增 **OpenList 兼容用户与会话能力**：默认管理员同步当前思源账号、disabled guest、JWT 登录/hash 登录、密码时间戳失效、`/api/me`、管理员用户 CRUD、用户响应脱敏，以及 Dock 用户管理。
- 新增主要运行时入口的权限校验：普通文件读写管理、搜索、压缩包、torrent generate/rapid-upload、分享管理和公开读取、WebDAV、S3。
- 新增多文件分享：自定义分享 ID、密码、过期时间、访问次数限制、Readme/Header、启用/禁用/删除、访问计数、`/sd` 下载，以及分享压缩包 meta/list/extract。
- 新增本地搜索索引接口：build、update、stop、clear、progress、`/api/fs/search`、忽略路径、挂载级 `disable_index` 和 OpenList 风格分页结果。
- 新增 torrent parse、upload_parse、单文件 generate、可选 189 `x-cas` 元数据，以及 rapid-upload driver-boundary 校验。
- 新增 ZIP stored/deflate、tar、tgz/tar.gz 压缩包 meta/list/extract/decompress，覆盖 `/ae`、`/ad`、`/ap`、分享 `@s` 路径和 `/sad` 分享压缩包提取。
- 新增 mounted ZIP range 读取和确定性的 GBK 文件名解码，百度网盘这类远端 ZIP 不再需要整包拉取也能正确显示中文文件名。
- 新增 115 Cloud 运行时：Cookie/二维码 Token 登录、分页列表、详情/读取/下载链接、基础 mkdir/move/copy/remove/rename、容量详情、限速和 Dock 表单字段。
- 新增更多驱动上传链路：123 网盘预签名/S3 上传、OneDrive 小文件和大文件 upload session、百度网盘分片上传、阿里云盘开放平台普通/秒传分支、Quark/UC 分片上传、QuarkOpen 上传、S3 直传预签名、WebDAV PUT，以及普通 189Cloud 上传请求和分片基础。
- 新增普通 189Cloud 账号登录、短信二次验证、Dock 验证专用流程，以及需要验证时更安全的文件浏览提示。
- 新增 Local 桌面端本地存储：通过前端 Electron runtime 访问本机文件系统，支持盘符枚举、挂载指定根目录、超时保护和跨盘移动降级。
- 新增原生思源文档形式的插件文档入口。打包文档放在 `assets/docs`，API 文档直接从运行中的 `/api/public/api` 生成。

### 优化

- 按 OpenList 后端和前端参考继续收口内核源码目录、路由名、请求字段、响应 envelope 和 handler 边界。
- 将内核持久数据拆分为 `config.json`、`runtime.json` 和 `search-index.json`，支持旧状态迁移，并按配置/运行时/搜索索引分域保存。
- 优化 Dock 挂载编辑、FileTab 文件操作、右键菜单、压缩包浏览、当前目录搜索、Markdown/代理链接复制和驱动配置表单。
- 优化 `/api/public/api`、`/api/public/routes` 和 `/siyuan-cloud/status`，作为 companion 插件和本机自动化的轻量机器可读发现入口。
- 优化媒体播放路径，保持 `fs.Link -> /p or /d -> common proxy -> body.proxy`。
- 优化 WebDAV 和 S3 兼容：权限边界、bucket 到 path 映射、配置后 SigV4 签名，以及核心对象 list/multipart 流程。
- 优化文档体验：文档按语言目录组成文档树，驱动教程放在“驱动说明”父文档下。

### 修复

- 修复分享越权边界：公开 list/get/download/archive 访问时会重新检查 creator 状态、creator base_path 和 nearest meta 规则。
- 修复任务归属泄漏：任务记录写入 creator 信息，普通用户只能查看和操作自己的任务，管理员可见全量。
- 修复普通文件接口权限缺口：base_path、nearest meta 访问，以及 write/copy/move/remove/rename/offline 权限位。
- 修复 WebDAV 和 S3 读/管理权限处理，包括 legacy token 快捷入口和配置 S3 签名后的校验。
- 修复 archive read/decompress、torrent base_path、search 结果按 base_path/meta 过滤等权限边界。
- 修复百度等远端 ZIP 行为：避免整包拉取，支持 range 读取，并正确解码非 EFS 中文文件名。
- 修复 signed URL 代理请求形状：无 body 的 GET/HEAD forwardProxy 不再带 `contentType`、`payload`、`payloadEncoding`。
- 修复 189Cloud 短信验证循环和 Dock 挂载新增/编辑时序问题。
- 修复 Local 本地存储边界：宿主文件系统访问只放在桌面前端，不放进 kernel HTTP 层。
- 修复 API 文档臃肿问题：移除静态 API Markdown 模板，改为从 `/api/public/api` 直接生成最小运行时文档。

### 已知限制

> [!WARNING]
> 思盘当前仍是运行在思源内的兼容运行时，不是公网独立 OpenList 服务。

- 当前仍是 OpenList 兼容的思源 kernel runtime 子集，不是完整 OpenList 服务。
- 任务接口已对齐 OpenList 形态，但真实异步队列、取消传播、重试调度和进度上报仍待实现。
- 搜索使用本地持久索引，还不是完整 OpenList search backend 矩阵。

- RAR/7z/ISO reader 仍是占位，需要等 reader、许可证、打包路径和 fixture 都明确后再接入。
- `/ae` 压缩包内媒体目前偏向 entry 提取，不等同于普通 `/p` 的可 seek 流式播放。
- 离线下载工具和真实 189/189PC CAS rapid-upload 仍需要继续迁移。
