# 123Pan 挂载

本教程适用于 `123Pan`。

## 适合场景

- 浏览 123 网盘目录。
- 使用账号密码登录或导入 `access_token`。
- 下载、上传、创建目录、删除、重命名和移动文件。

## 挂载

1. 打开 <kbd>Dock</kbd> -> <kbd>挂载</kbd> -> <kbd>新增</kbd>。
2. 驱动选择 `123Pan`。
3. 挂载路径填写 `/123`。
4. 填写 `username` 和 `password`，或填入已有 `access_token`。
5. `root_folder_id` 默认 `0`。
6. 保存后浏览 `/123`。

| 推荐项 | 值 |
| --- | --- |
| 驱动 | `123Pan` |
| 挂载路径 | `/123` |
| `root_folder_id` | `0` |
| `UploadThread` | `3` |

## 字段

| 字段 | 说明 |
| --- | --- |
| `username` / `password` | **必填**，账号密码登录 |
| `access_token` | 已有访问 token |
| `root_folder_id` | 根目录 ID，默认 `0` |
| `UploadThread` | 上传并发 |
| `platform` | API 请求平台头，默认 `web` |

## 注意

- 当前运行时支持列表、详情、读取、链接、创建目录、删除、重命名、移动和上传。
- 下载倾向走代理路径。
- 上传会按上游返回选择预签名分片或 S3 上传。

## 排查

| 现象 | 处理 |
| --- | --- |
| 登录失败 | 检查账号密码或清空过期 `access_token` 后重试 |
| 上传失败 | 检查目标目录权限和网络稳定性 |
| 链接失效 | 刷新目录或重新打开文件 |
