# Local 本地存储挂载

本教程按思盘当前接入的 OpenList `Local` 驱动字段编写。

> [!TIP]
> Local 通过思源桌面端 Electron runtime 访问本机文件系统，只在桌面端可用；kernel HTTP 层只保留元数据，不代理本地磁盘。

## 适合场景

- 在思盘里浏览本机目录。
- 把本地图片、视频、文档复制为思源可用链接。
- 预览本地图片、文本、PDF、电子书、ZIP 压缩包。
- 在挂载目录内创建、上传、重命名、复制、移动和删除文件。

## 准备事项

- 使用思源桌面端。
- 确认思盘 Dock 可以打开。
- 准备一个要暴露给思盘的本机目录，例如 `E:\XianNi`。
- 如果要枚举所有磁盘，确认当前系统权限允许访问对应盘符或挂载点。

## 挂载指定目录

1. 打开 <kbd>Dock</kbd> -> <kbd>挂载</kbd> -> <kbd>新增</kbd>。
2. 驱动选择 `Local`。
3. 填写挂载路径，例如 `/Local`。
4. `root_folder_path` 填写本机目录，例如 `E:\XianNi`。
5. 保存后打开文件管理，浏览 `/Local`。

| 推荐项 | 值 |
| --- | --- |
| 驱动 | `Local` |
| 挂载路径 | `/Local` |
| `root_folder_path` | `E:\XianNi` |
| `show_hidden` | `true` 或按需关闭 |

## 枚举磁盘

如果 `root_folder_path` 填 `/`、`*` 或留空，思盘会把挂载点作为设备入口：

- Windows：枚举可访问的 `C:`、`D:`、`E:` 等盘符。
- macOS：显示 `/`、`~` 和 `/Volumes` 下的卷。
- Linux：显示 `/`、`~` 和 `/mnt`、`/media` 下的挂载点。

例如挂载路径为 `/Local` 时，Windows 盘符会显示为：

```text
/Local/C:
/Local/D:
/Local/E:
```

## 字段

| 字段 | 说明 |
| --- | --- |
| `root_folder_path` | 本机根目录；`/`、`*` 或留空表示枚举设备入口 |
| `directory_size` | 目录大小统计，可能影响宿主机性能 |
| `thumbnail` | 缩略图开关；当前本地浏览以文件列表和预览为主 |
| `thumb_cache_folder` | 缩略图缓存目录 |
| `thumb_concurrency` | 缩略图并发数 |
| `video_thumb_pos` | 视频缩略图位置 |
| `show_hidden` | 是否显示隐藏文件和目录 |
| `mkdir_perm` | OpenList 兼容字段，桌面端本地创建主要按系统权限执行 |
| `recycle_bin_path` | OpenList 兼容字段；当前删除走本地文件删除逻辑 |

## 能力

- 列表：读取挂载目录或设备入口。
- 预览：图片、文本、PDF、电子书、压缩包等按思盘现有文件类型逻辑打开。
- 媒体：本地文件返回 `file://` 链接，图片和视频复制链接会保持中文路径可读。
- 写入：支持创建目录、上传/创建文件、重命名、复制、移动、删除。
- 跨盘移动：系统 `rename` 失败时会降级为复制后删除。

## 验证

- [ ] <kbd>Dock</kbd> 中能看到 `/Local` 挂载。
- [ ] 文件管理能列出本地目录或盘符。
- [ ] 图片可以预览，复制出来的中文文件名路径可读。
- [ ] 视频复制为 `<video>` 时路径可读，空格保留为 `%20`。
- [ ] 可以在挂载目录内新建目录、上传文件、重命名和删除。
- [ ] ZIP 文件可以打开压缩包预览。

## 注意

> [!NOTE]
> Local 不是公网可访问存储。复制出来的 `file://` 链接只对当前电脑或路径一致的环境有效。

> [!WARNING]
> 不要把系统根目录、重要配置目录或敏感目录作为可写挂载长期使用。思盘会阻止修改设备入口，但挂载目录内的删除、移动等操作会作用到真实本机文件。

- Local 依赖桌面端 `window.require` 获取 Node `fs/path` 能力，浏览器端或移动端不可用。
- kernel 私有 HTTP 路由不会代理本地磁盘内容，分享链接也不能让其它设备下载你的本地文件。
- `root_folder_path` 指定目录时，思盘会限制访问不越出该根目录。

## 排查

| 现象 | 处理 |
| --- | --- |
| 挂载不显示 | 确认使用思源桌面端，并重新打开 Dock 或刷新状态 |
| 目录为空 | 检查 `root_folder_path` 是否真实存在，或当前用户是否有权限访问 |
| 访问超时 | 避免挂载响应很慢的网络盘、休眠盘或不可用设备 |
| 修改失败 | 检查系统文件权限，或目标是否是设备入口 |
| 分享无法下载 | Local 只暴露当前电脑本地文件，不能作为公网下载源 |
