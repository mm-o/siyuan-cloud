# S3 兼容存储

本教程适用于 `S3` 和 `Doge`。

## 适合场景

- 接入 AWS S3、MinIO、R2、DogeCloud 或其它 S3 兼容对象存储。
- 浏览 bucket 内对象并通过思盘下载、预览、上传和管理。
- 使用预签名 URL 或思盘代理路径访问对象。

## 挂载

1. 打开 <kbd>Dock</kbd> -> <kbd>挂载</kbd> -> <kbd>新增</kbd>。
2. 驱动选择 `S3` 或 `Doge`。
3. 挂载路径填写 `/S3`。
4. 填写 `bucket`、`endpoint`、`region`、`access_key_id`、`secret_access_key`。
5. 按服务要求选择是否开启 `force_path_style`。
6. 保存后浏览 `/S3`。

| 推荐项 | 值 |
| --- | --- |
| 驱动 | `S3` |
| 挂载路径 | `/S3` |
| `root_folder_path` | `/` |
| `sign_url_expire` | `4` |

## 字段

| 字段 | 说明 |
| --- | --- |
| `bucket` | **必填**，桶名 |
| `endpoint` | **必填**，S3 endpoint |
| `region` | 区域 |
| `access_key_id` / `secret_access_key` | **必填**，访问密钥 |
| `session_token` | 临时凭证 token |
| `custom_host` | 自定义访问域名 |
| `enable_custom_host_presign` | 预签名时使用自定义域名 |
| `force_path_style` | 路径风格访问，MinIO 常用 |
| `list_object_version` | `v1` 或 `v2` |
| `enable_direct_upload` | 启用直传信息 |
| `direct_upload_host` | 直传 host |

## 注意

- 文件 `raw_url` 默认返回思盘 `/d/<path>`。
- 开启 `enable_direct_upload` 后会暴露直传工具信息。
- `Doge` 复用 S3 兼容字段。

## 排查

| 现象 | 处理 |
| --- | --- |
| 列表失败 | 检查 bucket、endpoint、region 和签名版本 |
| 上传失败 | 检查 AK/SK 权限和 bucket 写权限 |
| 链接无法访问 | 检查 `custom_host`、预签名过期时间和公网访问策略 |
