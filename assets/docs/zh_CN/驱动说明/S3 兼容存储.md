# S3 兼容存储

本教程适用于 `S3` 和 `Doge`。

## 适合场景

- 接入 AWS S3、MinIO、R2、DogeCloud 或其它 S3 兼容对象存储。
- 浏览 bucket 内对象并通过思盘下载、预览、上传和管理。
- 使用预签名 URL 或思盘代理路径访问对象。

## 挂载

1. 打开 <kbd>Dock</kbd> -> <kbd>挂载</kbd> -> <kbd>新增</kbd>。
2. 驱动选择 `S3` 或 `Doge`。
3. 挂载路径填写 `/S3`。
4. 填写 `bucket`、`endpoint`、`region`、`access_key_id`、`secret_access_key`。
5. 按服务要求选择是否开启 `force_path_style`。
6. 保存后浏览 `/S3`。

| 推荐项 | 值 |
| --- | --- |
| 驱动 | `S3` |
| 挂载路径 | `/S3` |
| `root_folder_path` | `/` |
| `sign_url_expire` | `4` |

## 字段

| 字段 | 说明 |
| --- | --- |
| `bucket` | **必填**，桶名 |
| `endpoint` | **必填**，S3 API endpoint。必须填写带 `http://` 或 `https://` 的绝对 URL，例如 `https://s3.cn-south-1.qiniucs.com` |
| `region` | 区域 |
| `access_key_id` / `secret_access_key` | **必填**，访问密钥 |
| `session_token` | 临时凭证 token |
| `custom_host` | 自定义访问域名 |
| `enable_custom_host_presign` | 预签名时使用自定义域名 |
| `force_path_style` | 路径风格访问，MinIO 常用 |
| `list_object_version` | `v1` 或 `v2` |
| `remove_bucket` | 使用自定义域名时从访问路径中移除 bucket |
| `add_filename_to_disposition` | 在下载响应头中写入文件名 |
| `enable_direct_upload` | 启用直传信息 |
| `direct_upload_host` | 直传 host |

## 常见填写格式

`bucket` 只填桶名，`endpoint` 只填服务端点，不要把 bucket 拼进 endpoint。当前 S3 驱动与 OpenList 保持一致，不会自动补协议；缺少 `https://` 时会报 `URL is not absolute`。

| 服务 | `bucket` 示例 | `endpoint` 示例 | `region` 示例 | `force_path_style` 建议 |
| --- | --- | --- | --- | --- |
| 缤纷云 S4 | `your-bucket` | `https://s3.bitiful.net` | `cn-east-1` | 通常关闭；若服务端提示 path-style 再开启 |
| 七牛云 Kodo 华南广东 | `your-bucket` | `https://s3.cn-south-1.qiniucs.com` | `cn-south-1` | 可开启，七牛同时支持 path-style 和 virtual-host style |
| 七牛云 Kodo 华东浙江 | `your-bucket` | `https://s3.cn-east-1.qiniucs.com` | `cn-east-1` | 可开启 |
| AWS S3 | `your-bucket` | `https://s3.<region>.amazonaws.com` | `us-east-1`、`ap-east-1` 等 | 通常关闭；如遇兼容问题再开启 |
| 腾讯云 COS | `your-bucket` | `https://cos.<Region>.myqcloud.com`，例如 `https://cos.ap-guangzhou.myqcloud.com` | `auto` 或服务要求的值 | 通常关闭；如遇兼容问题再开启 |
| 阿里云 OSS S3 兼容 | `your-bucket` | `https://s3.oss-<region>.aliyuncs.com`，例如 `https://s3.oss-cn-hangzhou.aliyuncs.com` | `cn-hangzhou` 等 | 通常关闭；如遇兼容问题再开启 |
| 华为云 OBS | `your-bucket` | `https://obs.<region>.myhuaweicloud.com`，例如 `https://obs.cn-north-4.myhuaweicloud.com` | `cn-north-4` 等 | 通常关闭；如遇兼容问题再开启 |
| 火山引擎 TOS | `your-bucket` | `https://tos-s3-<region>.volces.com`，例如 `https://tos-s3-cn-beijing.volces.com` | `cn-beijing` 等 | 通常关闭；按控制台的 S3 Endpoint 为准 |
| 又拍云云存储 | `your-bucket` | `https://s3.api.upyun.com` | 可留空或按服务要求填写 | 可开启，又拍云支持 path-style 和 virtual-host style |
| Cloudflare R2 | `your-bucket` | `https://<account_id>.r2.cloudflarestorage.com` | `auto` | 建议开启 |
| MinIO | `your-bucket` | `https://minio.example.com` 或 `http://192.168.1.10:9000` | `us-east-1` | 通常开启 |
| Backblaze B2 | `your-bucket` | `https://s3.<region>.backblazeb2.com` | `us-west-004` 等 | 通常关闭；如遇兼容问题再开启 |
| DigitalOcean Spaces | `your-space` | `https://<region>.digitaloceanspaces.com`，例如 `https://nyc3.digitaloceanspaces.com` | `nyc3` 等 | 通常关闭 |
| DogeCloud | 按 DogeCloud 控制台 | 按 DogeCloud S3 endpoint | 按 DogeCloud 控制台 | 按服务端提示 |

不同厂商的 S3 兼容程度和签名规则会有差异。若表格示例和控制台显示不一致，优先使用控制台或官方文档里的 S3 API endpoint，不要使用对象外链、CDN 域名或网页控制台地址。

七牛云常见 Region ID：

| 区域 | `region` | `endpoint` |
| --- | --- | --- |
| 华东-浙江 | `cn-east-1` | `https://s3.cn-east-1.qiniucs.com` |
| 华东-浙江2 | `cn-east-2` | `https://s3.cn-east-2.qiniucs.com` |
| 华北-河北 | `cn-north-1` | `https://s3.cn-north-1.qiniucs.com` |
| 华南-广东 | `cn-south-1` | `https://s3.cn-south-1.qiniucs.com` |
| 北美-洛杉矶 | `us-north-1` | `https://s3.us-north-1.qiniucs.com` |
| 亚太-新加坡 | `ap-southeast-1` | `https://s3.ap-southeast-1.qiniucs.com` |
| 亚太-河内 | `ap-southeast-2` | `https://s3.ap-southeast-2.qiniucs.com` |

不要这样填：

| 错误写法 | 原因 |
| --- | --- |
| `bucket.s3.region.qiniucs.com` | 这是模板写法，不是真实 endpoint，且缺少协议 |
| `s3.cn-south-1.qiniucs.com` | 缺少 `https://`，不是绝对 URL |
| `https://siyuan-mediaplayer.s3.cn-south-1.qiniucs.com` 且 `bucket=siyuan-mediaplayer` | 一般会把 bucket 重复拼入请求；除非你明确要配自定义 host，否则 endpoint 填服务端点即可 |
| 对象外链域名、CDN 域名或静态网站域名 | 这些通常不是 S3 API endpoint，不能用于签名的 list/put/delete 请求 |

## 注意

- 文件 `raw_url` 默认返回思盘 `/d/<path>`。
- `/api/fs/link` 会返回 OpenList 风格的 GET 预签名 URL；`/p/<path>` 会保留思盘稳定路径，由插件用 S3 签名请求读取，适合思阅/PDF.js 这类会发起 Range 请求的预览场景。
- `/p/<path>` 会把 Range 请求转发给上游对象存储，PDF 阅读器和媒体组件可以通过稳定的插件路径读取分段内容。
- 目录识别、列表分页、目录 marker 过滤，以及目录复制、移动、删除、重命名的递归处理均按 OpenList S3 行为对齐。默认目录占位文件名为 `.siyuan-cloud`。
- 开启 `enable_direct_upload` 后会暴露直传工具信息。
- `Doge` 复用 S3 兼容字段。
- 多吉云专用说明见 [[DogeCloud 挂载]]。
- 如果对象存储服务要求 path-style，请开启 `force_path_style`；MinIO、R2、部分兼容服务通常需要它。
- 如果只想换公开访问域名，优先使用 `custom_host`，不要把 CDN 域名填到 `endpoint`。
- 缤纷云 S4 通常使用 `endpoint=https://s3.bitiful.net`、`region=cn-east-1`、`force_path_style=false`；如果使用绑定域名或 CDN，只放到 `custom_host`，不要放到 `endpoint`。

## 排查

| 现象 | 处理 |
| --- | --- |
| `URL is not absolute` | `endpoint` 没有带 `https://` 或 `http://` |
| 列表失败 | 检查 bucket、endpoint、region 和签名版本 |
| 上传失败 | 检查 AK/SK 权限和 bucket 写权限 |
| 链接无法访问 | 检查 `custom_host`、预签名过期时间和公网访问策略 |
| PDF 能下载但思阅打不开 | 优先确认 `endpoint` 是 S3 API 端点而不是对象外链/CDN；缤纷云通常关闭 `force_path_style`；若使用自定义访问域名，填写到 `custom_host` 并按域名策略决定是否开启 `enable_custom_host_presign` |
