# 思源工作空间

本教程适用于 `SiYuanWorkspace` 驱动。

## 适合场景

- 在思盘里浏览当前思源工作空间文件。
- 用思源原生资源路径打开工作空间里的 assets、public、PDF、图片、音频和视频。
- 复制稳定的工作空间公开资源相对链接，不带 localhost 端口。
- 通过 OpenList 兼容的文件管理界面读取工作空间文件。

## 挂载

1. 打开 <kbd>Dock</kbd> -> <kbd>挂载</kbd> -> <kbd>新增</kbd>。
2. 驱动选择 `SiYuanWorkspace`。
3. 填写挂载路径，例如 `/Workspace` 或 `/思源工作空间`。
4. `root_folder_path` 填 `/@workspace` 表示工作空间根目录，也可以填 `/@workspace/data/assets` 这样的子目录。
5. 保存后在文件管理中浏览挂载路径。

| 推荐项 | 值 |
| --- | --- |
| 驱动 | `SiYuanWorkspace` |
| 挂载路径 | `/Workspace` |
| `root_folder_path` | `/@workspace` |

## 字段

| 字段 | 说明 |
| --- | --- |
| `root_folder_path` | 工作空间根目录或子目录；使用 `/@workspace` 表示整个工作空间 |

## 公开资源链接

工作空间 `data/<name>/...` 下的文件会使用思源原生公开资源路径：

```text
/@workspace/data/assets/a.mp4 -> /assets/a.mp4
/@workspace/data/public/a.pdf -> /public/a.pdf
```

挂载后也遵循同一规则：

```text
/思源工作空间/data/assets/a.mp4 -> /assets/a.mp4
/思源工作空间/data/public/a.pdf -> /public/a.pdf
```

这样媒体预览更快，复制出来的链接也稳定。复制链接不会带 `https://127.0.0.1:<端口>` 这类会变化的地址。

## 注意

- `SiYuanWorkspace` 是唯一可手动添加的思源内置驱动；`SiYuanKernel` 只作为思盘内部能力，不作为挂载驱动暴露。
- 公开资源路径只保证在当前思源环境内稳定。
- 非公开工作空间文件仍会回退到思盘私有 `/p` 或 `/d` 路径。
- 写入能力保持保守，因为工作空间写入必须遵守思源文件安全边界。

## 验证

- [ ] Dock 和文件管理中能看到工作空间挂载。
- [ ] `/思源工作空间/data/assets/...` 媒体能以 `/assets/...` 打开。
- [ ] `/思源工作空间/data/public/...` 文件能以 `/public/...` 打开。
- [ ] 复制链接使用稳定相对路径，不带 localhost 地址。

## 排查

| 现象 | 处理 |
| --- | --- |
| directory not found | 检查 `root_folder_path`，使用 `/@workspace` 或已存在的工作空间子目录 |
| 媒体仍走 `/plugin/private/.../p` | 刷新文件列表，并确认文件位于 `data/<name>/...` 下 |
| 复制链接在其它环境不可用 | 工作空间公开资源链接只面向当前思源工作空间环境 |
