# 百度网盘挂载

本教程按 OpenList 百度网盘驱动说明整理，并补充思盘当前运行时的测试边界。上游参考：<https://doc.oplist.org/guide/drivers/baidu>

> [!TIP]
> 思盘新建百度挂载时默认 `download_api=crack_video`。当前实现会让视频/音频走 `crack_video`，其它文件自动回退 `official`，避免 PDF、EPUB、图片等非媒体文件误进视频接口。

## 适合场景

- 在思盘中浏览百度网盘目录。
- 通过 `/p/<path>` 代理播放视频或音频。
- 复制 OpenList 兼容的文件链接、下载链接或文档链接。
- 预览远端 ZIP 压缩包，包含百度挂载 ZIP 的 range 读取。
- 上传普通文件到百度网盘。

## 准备事项

- 一个可用的百度网盘账号。
- 一个有效的 `refresh_token`。
- 思盘 Dock 可以打开，并能进入 <kbd>挂载</kbd> 页。
- 网络出口尽量稳定。百度下载链接对出口 IP、UA、代理环境比较敏感。

## 获取 refresh_token

OpenList 官方文档提供三种获取方式。思盘只需要最终拿到 `refresh_token` 后填入挂载表单。

1. 官方在线工具：<https://api.oplist.org/>
2. OpenList 文档中的百度网盘工具页：<https://doc.oplist.org/guide/drivers/baidu>
3. 自建百度 OAuth 应用：填写自己的 `client_id` 和 `client_secret`，并关闭或绕过在线刷新 API。

> [!IMPORTANT]
> 使用官方在线工具时，务必勾选“使用 OpenList 提供的参数”。勾选后通常保持 `client_id` / `client_secret` 为空即可；只有使用自建百度 OAuth 应用时才填写自己的参数。

使用在线工具时，保留默认的 `api_url_address` 即可：

```text
https://api.oplist.org/baiduyun/renewapi
```

## 挂载

1. 打开 <kbd>Dock</kbd> -> <kbd>挂载</kbd>，使用底部的 <kbd>添加</kbd>。
2. 驱动选择 `BaiduNetdisk`。
3. 填写挂载路径，例如 `/Baidu`。
4. 填写 `refresh_token`。
5. `root_folder_path` 通常保持 `/`；只挂载子目录时填写百度网盘内的真实路径。
6. `download_api` 建议先保持 `crack_video`。
7. 保存后打开文件管理，浏览 `/Baidu`。

| 推荐项 | 值 |
| --- | --- |
| 驱动 | `BaiduNetdisk` |
| 挂载路径 | `/Baidu` |
| `root_folder_path` | `/` |
| `download_api` | `crack_video` |
| `custom_crack_ua` | `netdisk` |
| `api_url_address` | `https://api.oplist.org/baiduyun/renewapi` |

## 字段说明

| 字段 | 说明 |
| --- | --- |
| `refresh_token` | **必填**。用于刷新百度 `access_token`，思盘会在刷新成功后写回新的 token。 |
| `root_folder_path` | 百度网盘内的根路径，默认 `/`。例如只挂载 `/电影` 时填 `/电影`。 |
| `download_api` | 下载接口：`official`、`crack`、`crack_video`。思盘默认 `crack_video`，非媒体会回退 `official`。 |
| `use_online_api` | 使用在线 token 刷新 API。使用 `api.oplist.org` 时保持开启。 |
| `api_url_address` | 在线刷新 API 地址，默认 `https://api.oplist.org/baiduyun/renewapi`。 |
| `client_id` / `client_secret` | 自建百度 OAuth 应用时填写；使用在线工具时通常留空。 |
| `custom_crack_ua` | `crack` / `crack_video` 链接请求使用的 User-Agent，默认 `netdisk`。 |
| `upload_thread` | 上传线程数。当前实现按 OpenList 字段保留，普通测试先保持默认 `3`。 |
| `use_dynamic_upload_api` | 动态上传 API，默认开启。上传失败时可作为排查项临时关闭。 |
| `low_bandwith_upload_mode` | 低带宽上传模式，默认关闭。弱网环境上传不稳定时再尝试。 |
| `only_list_video_file` | 只列出视频文件。普通文件管理不要开启。 |
| `order_by` / `order_direction` | 列表排序字段和方向。 |

## download_api 选择

| 值 | 用途 | 建议 |
| --- | --- | --- |
| `official` | 使用官方 `filemetas` / `dlink` 路径。 | 最保守，适合普通文件下载排查。 |
| `crack` | 使用 OpenList 上游的破解链接路径。 | 需要特殊 UA，失败时先检查代理和 `custom_crack_ua`。 |
| `crack_video` | 使用百度视频接口获取媒体链接。 | 思盘默认推荐，当前仅媒体文件使用，非媒体回退 official。 |

> [!WARNING]
> OpenList 官方说明中提到，百度网盘大于 20M 的文件下载可能受 UA、账号和网络环境影响。思盘播放走 `fs.Link -> /p -> body.proxy`，但百度侧限制仍然存在。

## 逐项测试清单

- [ ] <kbd>Dock</kbd> 挂载列表能看到 `/Baidu`。
- [ ] 文件管理能列出百度网盘根目录。
- [ ] `root_folder_path` 改成子目录后，只显示该子目录内容。
- [ ] 普通小文件可以打开或下载。
- [ ] 视频文件的 `raw_url` 返回 `/plugin/private/siyuan-cloud/p/...`。
- [ ] 视频播放支持 Range，不会每个 Range 请求都重新逐层解析目录。
- [ ] 非媒体文件在 `download_api=crack_video` 时仍能走普通下载路径。
- [ ] 可以新建目录、重命名、删除测试文件。
- [ ] 可以上传一个小文件。
- [ ] ZIP 文件可以进入压缩包预览，中文文件名正常显示。

## 思盘当前边界

- 百度挂载默认 `PreferProxy`，所以 `raw_url` 通常是 `/p/<path>`，不是百度直链。
- 媒体播放统一走 OpenList 边界：`driver Link -> /p -> common proxy -> body.proxy`。
- 百度 ZIP 预览使用 range 读取，不再整包拉取。
- 压缩包内视频不是普通网盘视频播放；`/ae` 当前是 entry extract，不是完整 seekable proxy。
- 链接、文件对象和目录列表有短期缓存，用于减少播放器 Range 请求导致的重复解析。

## 排查

| 现象 | 处理 |
| --- | --- |
| 提示 `empty refresh_token` | 重新获取 `refresh_token` 并保存挂载。 |
| 登录或刷新 token 失败 | 检查 `api_url_address` 是否可访问；使用自建 OAuth 时检查 `client_id` / `client_secret`。 |
| 目录为空 | 检查 `root_folder_path` 是否存在，路径必须是百度网盘内真实目录。 |
| 播放失败 | 先关闭系统代理或网络代理，再刷新目录重新播放。 |
| 大文件下载失败 | 先切到 `official` 排查，再检查 UA、账号状态和网络出口。 |
| 非媒体文件下载异常 | 如果改过 `download_api`，先恢复 `crack_video` 或 `official`。 |
| ZIP 中文乱码 | 确认使用当前版本；思盘已内置 GBK 文件名解码。 |
| 上传失败 | 先用小文件测试；再尝试关闭 `use_dynamic_upload_api` 或开启 `low_bandwith_upload_mode`。 |
