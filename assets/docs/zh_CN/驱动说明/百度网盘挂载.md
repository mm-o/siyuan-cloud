# 百度网盘挂载

本教程按思盘当前接入的 OpenList `BaiduNetdisk` 驱动字段编写。

> [!TIP]
> `download_api` 建议先保持 `crack_video`，这是思盘默认用于媒体播放的路径。

{{{row

{{{col

## 适合场景

- 在思盘里浏览百度网盘目录。
- 复制文件下载链接或文档链接。
- 通过 `/p/<path>` 走代理播放。
- 预览远端 ZIP 压缩包。

}}}

{{{col

## 准备事项

- 一个可用的百度网盘账号。
- 有效的 `refresh_token`。
- 思盘 Dock 已能打开。
- 网络出口尽量稳定，避免代理频繁切换。

}}}

}}}

## 挂载

1. 打开 <kbd>Dock</kbd> -> <kbd>挂载</kbd> -> <kbd>新增</kbd>。
2. 驱动选择 `BaiduNetdisk`。
3. 填写挂载路径，例如 `/Baidu`。
4. 填写 `refresh_token`。
5. `download_api` 建议保持 `crack_video`，媒体播放更快；需要保守上游路径时改为 `official`。
6. 保存后打开文件管理，浏览 `/Baidu`。

| 推荐项 | 值 |
| --- | --- |
| 驱动 | `BaiduNetdisk` |
| 挂载路径 | `/Baidu` |
| `download_api` | `crack_video` |
| `root_folder_path` | `/` |

## 字段

| 字段 | 说明 |
| --- | --- |
| `refresh_token` | **必填**，用来刷新百度 access token |
| `download_api` | `official`、`crack`、`crack_video`；思盘默认使用 `crack_video` |
| `use_online_api` | 通常保持开启；只有自备百度 OAuth 应用时才关闭 |
| `api_url_address` | 刷新令牌 API，默认 `https://api.oplist.org/baiduyun/renewapi` |
| `client_id` / `client_secret` | 自备 OAuth 应用时填写 |
| `custom_crack_ua` | crack 链接接口使用的 User-Agent，默认 `netdisk` |
| `root_folder_path` | 远端根目录，默认 `/` |
| `order_by` / `order_direction` | 列表排序 |

## 验证

- [ ] <kbd>Dock</kbd> 中能看到 `/Baidu` 挂载。

## 注意

> [!NOTE]
> 百度网盘默认偏向代理播放，`raw_url` 通常会返回 `/p/<path>`。

> [!WARNING]
> 百度链接对出口 IP 比较敏感。如果播放失败，先尝试关闭系统代理或网络代理。

- 媒体播放路径是 `fs.Link -> /p -> body.proxy`；其它插件直接消费返回的 `raw_url`。
- ZIP 预览使用 range 读取。普通视频播放和压缩包内视频播放不是同一条链路。

}}}

}}}

## 排查

| 现象 | 处理 |
| --- | --- |
| 播放失败 | 先关闭系统代理或网络代理，再重试 |
| 目录为空 | 检查 `root_folder_path` 是否指向真实目录 |
| 链接过期 | 重新打开文件或刷新目录，让思盘重新解析链接 |
| 登录失效 | 更新 `refresh_token` 后重新保存挂载 |
