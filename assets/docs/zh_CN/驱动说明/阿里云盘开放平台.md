# 阿里云盘开放平台

本教程适用于 `AliyundriveOpen`。

## 适合场景

- 接入阿里云盘开放平台账号。
- 浏览资源库、备份盘或默认盘。
- 上传、下载、移动、复制、删除和重命名文件。

## 挂载

1. 打开 <kbd>Dock</kbd> -> <kbd>挂载</kbd> -> <kbd>新增</kbd>。
2. 驱动选择 `AliyundriveOpen`。
3. 挂载路径填写 `/Aliyun`。
4. 填写 `refresh_token`。
5. `drive_type` 通常保持 `resource`。
6. 保存后浏览 `/Aliyun`。

| 推荐项 | 值 |
| --- | --- |
| 驱动 | `AliyundriveOpen` |
| 挂载路径 | `/Aliyun` |
| `drive_type` | `resource` |
| `root_folder_id` | `root` |
| `use_online_api` | `true` |

## 字段

| 字段 | 说明 |
| --- | --- |
| `drive_type` | `default`、`resource` 或 `backup` |
| `refresh_token` | **必填**，刷新访问令牌 |
| `root_folder_id` | 根目录 ID，默认 `root` |
| `use_online_api` | 使用在线刷新 API |
| `api_url_address` | token 刷新 API |
| `client_id` / `client_secret` | 自备应用时填写 |
| `remove_way` | `trash` 或 `delete` |
| `rapid_upload` | 秒传分支 |
| `internal_upload` | 内网上传地址 |
| `livp_download_format` | `jpeg` 或 `mov` |

## 注意

- 当前运行时支持 token 刷新、列表、详情、读取、链接、管理和上传。
- 上传会按上游响应选择普通上传或秒传。
- `no_overwrite_upload` 已开启，避免覆盖同名文件。

## 排查

| 现象 | 处理 |
| --- | --- |
| token 失效 | 更新 `refresh_token` 后重新保存 |
| 目录不对 | 检查 `drive_type` 和 `root_folder_id` |
| 上传失败 | 关闭 `internal_upload` 或检查网络出口 |
