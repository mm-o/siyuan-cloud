# 阿里云盘开放平台

本教程适用于 `AliyundriveOpen`。这是 OpenList 推荐的阿里云盘官方开放平台驱动，适合挂载资源库、备份盘或默认盘。

## 获取 refresh_token

1. 打开 OpenList 文档中的阿里云盘开放平台 token 获取入口。
2. **重点：使用官方在线工具时，勾选“使用 OpenList 提供的参数”。** 勾选后通常不需要填写 `client_id` 和 `client_secret`。
3. 用阿里云盘账号授权后复制 `refresh_token`。
4. 新建或更新挂载时填入 `refresh_token`，保存后驱动会自动刷新并写回新的 `refresh_token` 与 `access_token`。

如果你使用自己的开放平台应用，关闭 `use_online_api`，并填写 `client_id` 与 `client_secret`。

## 挂载

1. 打开 <kbd>Dock</kbd> -> <kbd>挂载</kbd> -> <kbd>新增</kbd>。
2. 驱动选择 `AliyundriveOpen`。
3. 挂载路径填写 `/Aliyun`。
4. 填写 `refresh_token`。
5. 一般保持 `drive_type=resource`、`root_folder_id=root`。
6. 保存后浏览 `/Aliyun`。

| 推荐项 | 值 |
| --- | --- |
| 驱动 | `AliyundriveOpen` |
| 挂载路径 | `/Aliyun` |
| `drive_type` | `resource` |
| `root_folder_id` | `root` |
| `use_online_api` | `true` |
| `alipan_type` | `default` |
| `remove_way` | `trash` |

## 字段

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `drive_type` | `resource` | 云盘类型，可选 `default`、`resource`、`backup`。 |
| `root_folder_id` | `root` | 挂载根目录 ID。 |
| `refresh_token` | 无 | 必填，用于刷新访问令牌。 |
| `order_by` | 空 | 排序字段，可选 `name`、`size`、`updated_at`、`created_at`。 |
| `order_direction` | 空 | 排序方向，可选 `ASC`、`DESC`。 |
| `use_online_api` | `true` | 使用在线 token 刷新 API。 |
| `alipan_type` | `default` | 在线刷新接口类型，可选 `default`、`alipanTV`。 |
| `api_url_address` | `https://api.oplist.org/alicloud/renewapi` | 在线 token 刷新 API 地址。 |
| `client_id` | 空 | 自备开放平台应用时填写；使用在线 API 时可留空。 |
| `client_secret` | 空 | 自备开放平台应用密钥；使用在线 API 时可留空。 |
| `remove_way` | `trash` | 删除方式，`trash` 移入回收站，`delete` 直接删除。 |
| `rapid_upload` | `false` | 开启秒传分支。上游说明启用后会先上传到服务器，进度可能不准确。 |
| `internal_upload` | `false` | 北京阿里云 ECS 可开启，上传 URL 会替换为内网地址。 |
| `livp_download_format` | `jpeg` | `.livp` 下载格式，可选 `jpeg`、`mov`。 |
| `access_token` | 自动写回 | 运行时刷新后保存，通常不需要手动填写。 |

## 已接入能力

- token 刷新：对齐上游 `_refreshToken`，支持在线 API 和自备 `client_id/client_secret`。
- 初始化：调用 `user/getDriveInfo`，按 `drive_type` 选择 `default_drive_id`、`resource_drive_id` 或 `backup_drive_id`。
- 列表：调用 `openFile/list`，分页读取并按 `order_by`、`order_direction` 排序。
- 下载：调用 `openFile/getDownloadUrl`，链接有效期按上游使用 `14400` 秒；`.livp` 会回退到 `streamsUrl[livp_download_format]`。
- 管理：支持新建文件夹、移动、复制、删除、重命名。
- 视频预览：`/api/fs/other` 的 `video_preview` 调用 `openFile/getVideoPreviewPlayInfo`。
- 容量详情：调用 `user/getSpaceInfo` 返回总空间、已用空间和剩余空间。
- 上传：对齐上游 `upload.go` 的 `openFile/create -> upload_url PUT -> openFile/complete`。

## 上传行为

- 普通上传默认按 20 MiB 分片。
- 大文件按上游阈值调整分片大小，避免超过 10000 个分片。
- `rapid_upload=true` 且文件大于 100 KiB 时，先提交前 1024 字节 SHA1 `pre_hash`。
- 如果接口返回 `PreHashMatched`，驱动会再次提交完整 SHA1 `content_hash`、`proof_version=v1` 和基于 access token 计算的 `proof_code`。
- 非秒传时按接口返回的 `part_info_list[].upload_url` 上传分片，再调用 `openFile/complete`。
- `internal_upload=true` 时，会把 `https://cn-beijing-data.aliyundrive.net/` 替换为北京内网 OSS 地址。

## 和 OpenList 的差异

- 本项目运行在思源插件环境中，上传输入来自内核 HTTP 接口；普通上传和秒传路径已按 OpenList 主流程实现。
- 为减少播放器 Range 请求重复逐层解析路径，运行时增加了短期 list/file/link 缓存；管理操作和上传后会清理缓存。
- OpenList 上游在移动、复制、重命名后会尝试清理同名重复文件；当前运行时已保留 `check_name_mode/auto_rename` 的主要语义，但没有额外执行重复文件清理请求。

## 排查

| 现象 | 处理 |
| --- | --- |
| token 失效 | 重新获取 `refresh_token`，保存挂载。 |
| 提示 `empty ClientID or ClientSecret` | 开启 `use_online_api`，或填写自备应用的 `client_id/client_secret`。 |
| 目录不对 | 检查 `drive_type` 和 `root_folder_id`。 |
| 删除后文件进回收站 | 将 `remove_way` 改为 `delete` 可直接删除。 |
| 上传失败 | 关闭 `internal_upload` 后重试，或检查当前网络是否能访问上传 URL。 |
| `.livp` 下载不符合预期 | 调整 `livp_download_format` 为 `jpeg` 或 `mov`。 |
