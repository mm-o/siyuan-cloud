# 思盘动态文件列表块设计

**状态：** 用户已确认第一版范围。

## 背景

目前思盘的 `/思盘` 斜杠命令会打开文件树；选中单个项目后，思盘用 `openListDocumentLink` 生成 Markdown 链接并插入光标。它没有把目录内容嵌入笔记。

「思播」和 [siyuan-folder](https://github.com/Reagan1947/siyuan-folder) 都通过 `;;;插件名/块类型` 插入思源原生自定义块，并由插件注册的 `customBlockRenders` 渲染交互界面。`siyuan-folder` 的目录由块独占，存放在思源 `assets` 中；思盘的数据源是已挂载的本地或网盘目录，不能把远端文件复制到思源资源目录。

## 目标

- 增加独立的斜杠命令，让用户选择一个已挂载目录并插入动态文件列表块。
- 块中浏览所选目录的当前内容；文件夹可在块内进入，面包屑可返回上级。
- 提供手动刷新和“在思盘文件管理器中打开”操作。
- 点击文件时在思盘完整文件管理器中定位到该文件。
- 原有 `/思盘` 单文件链接插入流程保持不变。

## 数据与渲染

- 自定义块类型使用 `file-list`，fence 命名空间为 `siyuan-cloud`。
- 块内容保存版本化的挂载路径和显示名称，并提供一个打开该目录的 Markdown 备用链接。
- 运行时通过现有 `fsList` 读取内容，因此继续复用挂载解析、驱动和鉴权路径。
- 块不缓存文件副本、不存储网盘凭据。复制块会引用同一个挂载路径。
- 当前浏览到的子目录只保存在块的运行时状态；重新渲染后回到块记录的起始目录。

## 第一版范围

- 只读浏览：目录导航、文件/文件夹行、加载/空目录/错误状态、手动刷新、跳转完整文件管理器。
- 块内不上传、创建、重命名、移动、分享或删除文件；这些操作继续使用已有文件管理器。
- 不做短周期后台轮询。块首次渲染时读取，用户可手动刷新，避免对云端驱动产生不必要的请求。
- 文件列表使用思源主题变量和 `b3-*` 基础样式；新增界面文案同时维护中文和英文 i18n。

## 异常与兼容

- 目录已卸载、无权限或网络请求失败时，块显示可读错误、重试入口和打开完整文件管理器的入口。
- 无效或不支持的块内容显示安全的文本回退，不发起路径请求。
- 块只记录规范化后的绝对 OpenList 路径；真实读取仍经过思盘现有 API 和后端权限校验。
- 如果思盘未启用，自定义界面不可用，但 fence 正文中的目录链接仍可作为手动打开入口。

## 验收标准

1. 新斜杠命令只允许选择目录，并在光标处插入 `siyuan-cloud/file-list` 自定义块。
2. 插入后，块显示所选目录的真实内容；可进入子目录、返回上级、手动刷新。
3. 块内入口可在思盘完整文件管理器中打开当前目录。
4. 不复制、不上传文件到思源 `assets`；已有 `/思盘` 文件链接行为不变。
5. 自定义块卸载或销毁时释放 Vue 组件和异步请求资源。
